# FP DAM · Programación

Prácticas y exámenes del módulo de Programación del ciclo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**, organizados por unidad formativa.

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)

> [!NOTE]
> Repositorio de formación: cada carpeta es un ejercicio independiente.

## Contenido

| Unidad | Tema | Ejercicios |
|---|---|---|
| UF1 | Programación básica | Bucles, listas y examen |
| UF2 | Diseño modular | Biblioteca, módulos de fechas, proyecto del clima de Gavà y examen |
| UF3 | Gestión de ficheros | Práctica de ficheros y examen |
| UF4 | Programación orientada a objetos | Examen |
| UF5 | Librerías de clases fundamentales | Práctica del hotel y examen |

## Cómo ejecutar un ejercicio

**Requisitos:** Python 3.

Entra en la carpeta del ejercicio y ejecuta su archivo principal:

```bash
cd "UF2_DiseñoModular/Proyecto_Clima_Gava"
python main.py
```

El nombre del archivo principal puede cambiar en cada ejercicio.
